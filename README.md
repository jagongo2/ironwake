# IRONWAKE · 철의 항로

브라우저용 2D 픽셀 함선 전투 프로토타입. 외부 이미지, 폰트, 음원, 라이브러리를 사용하지 않습니다.

## 실행

`dist/index.html`을 Chrome 또는 Edge에서 여세요. 설치와 빌드 없이 실행됩니다. 키보드와 마우스가 필요합니다.

- **작전 개시:** 적 호위함 3척을 무력화하면 승리합니다.
- **사격 시험장:** 적의 사격을 중지한 상태에서 비행과 파괴를 시험합니다. 적 함선은 기동합니다.
- 함교가 파괴되거나 선체가 크게 소실되면 함선이 격침됩니다. 화면 밖 적의 방향과 거리는 가장자리 표식으로 확인할 수 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 수평 이동 · 상승 · 하강 |
| 마우스 | 조준 |
| 왼쪽 버튼 누르기 | 57 mm 기관포 연사 |
| Space | 180 mm 고폭탄, 재장전 5.5초 |
| Shift + 이동 | 긴급 추력 |
| Esc | 일시정지 / 계속 |
| R | 현재 모드로 재출격 |
| M | 소리 켜기 / 끄기 |

정상 상태에서는 자동으로 고도를 유지합니다. 추진기는 출력이 서서히 차오르고, 키를 놓아도 관성이 남습니다. 엔진을 잃으면 추력이 줄고 아래로 가라앉습니다. 기관포는 과열되면 냉각될 때까지 발사되지 않습니다. 함교의 밝은 창과 갈색 연료실을 노려 보세요.

설정에서 화면 흔들림, 섬광, 스캔라인, 음량을 조절할 수 있습니다. 녹색 홀로그램 설정창에는 투명한 격자, 잔광, 이동하는 스캔선과 미세한 투영 떨림이 있습니다. 화면 흔들림을 끄면 투영 움직임도 멈춥니다. OS의 움직임 줄이기 설정도 따릅니다. 첫 출격 클릭으로 합성 음향이 시작됩니다. 탭을 떠나면 자동으로 일시정지됩니다.

## 구현 범위

- 고정 60 Hz 물리 업데이트, 중력, 관성, 추력 응답, 반동, 카메라 추적
- 선체·배경의 16색 팔레트와 기준 640×360에서 창 비율에 맞춰 확장되는 내부 해상도, 직접 작성한 함선 도트와 산업 지대 배경. 불과 잔광은 별도의 8단계 열색을 사용합니다.
- 함선 로컬 좌표계의 재질·내구도 격자, 포탄 궤적을 따라 검사하는 충돌
- 피격 위치의 실제 장갑 제거, 손상 후 연결성 검사, 분리된 덩어리의 낙하·회전
- 연료실 지연 유폭, 기관 손실에 따른 양력 감소, 함교 파괴와 격침
- 반동·탄착 섬광·충격파·불꽃·연기·파편과 Web Audio 합성 포격음·기관음
- 적 3척의 기동·예측 사격, 선체 간 분리와 충돌, 과열, 재장전, 승패, 재시작
- 파티클 3,200개, 분리 파편 70개, 공유 기류 격자 1개, 연료 공급원 14개 상한

이 버전은 전투의 조종감과 함선 파괴를 검증하는 작은 플레이 구간입니다. 지형 전체의 falling-sand 시뮬레이션, 액체 흐름, 함선 설계기, 캠페인, 세이브는 아직 포함하지 않습니다. 작은 파편은 시각 효과이며, 분리된 덩어리는 중력과 지면 충돌만 계산합니다.

## 검증

브라우저에서 시작, 이동, 연사, 장갑 손상, 일시정지, 설정 화면을 확인했습니다. 핵심 로직 검증에서는 호버링, 관성, 충돌 격자의 구멍, 구조 분리, 연료 유폭 예약, 고폭탄 명중, 기관 손실, 승패 전환, 적 3척 격침 경로를 확인했습니다. 180초 물리 시뮬레이션의 객체 수 상한과 좌표 유효성도 검사했습니다. 실제 여러 PC의 프레임률 측정은 아직 하지 않았습니다.

## 수정

게임의 CSS와 JavaScript는 모두 `dist/index.html` 안에 있습니다. 파일 상단의 `PAL`, `Ship`, `damage`, `detach`, `update`, `render`가 주요 수정 지점입니다. `.openai/hosting.json`은 기존 비공개 배포의 식별자를 유지합니다.

## 0.2 — 불과 홀로그램

불은 큰 사각형 파티클 대신 1픽셀 열 셀의 상승·확산과 개별 불씨를 조합합니다. 연료실과 잔해에는 지속 불길이 남고, 화염의 황백색 중심부에서 주황색·적색 가장자리로 식으며 부드러운 잔광을 더합니다. 불씨는 난류와 부력에 반응하고, 일부 불씨·불꽃·금속 파편은 선체 표면 및 지면에 닿아 튕기거나 식습니다. 연기는 불규칙한 픽셀 마스크로 팽창하고, 엔진 분사도 가는 픽셀 줄기로 바뀌었습니다.

이는 국소적인 시각 효과용 열 격자와 입자 물리입니다. 게임 전체 재질의 연소·전파나 완전한 유체 시뮬레이션은 구현하지 않았습니다. 기존 전투 검증에 더해 열 격자의 생성, 가시 픽셀 출력, 불씨 방출, 수명 종료 및 재출격 시 정리를 검사했습니다.

## 0.3 — 공유 기류 기반 연소

화원별로 같은 모양의 불기둥을 만드는 방식을 제거했습니다. 모든 화원이 월드 좌표의 한 기류장에 연료와 열을 공급하며, 기체의 속도·열·연료·연기를 초당 30회 갱신합니다. 부력, 이류, 압력 보정, 와류 보정을 통해 불길이 휘고 갈라지며 서로 영향을 줍니다. 연소량은 남은 연료, 온도와 연료·연기의 농도에 따라 계산합니다. 공급량도 비주기적으로 변화하며 연료가 소진되면 불이 사그라듭니다.

함선이 움직이면 새 연료만 함선을 따라 이동하고, 이미 방출된 뜨거운 기체는 원래 월드 위치에 남아 흐릅니다. 장갑의 재질 격자를 장애물로 사용하므로 기류가 선체를 우회합니다. 포격의 가스 팽창도 같은 속도장에 충격을 줍니다. 불씨와 연기 입자는 이 공유 기류를 따라 움직입니다. 화면에 그릴 불의 외곽선이나 반복 애니메이션은 저장하지 않습니다.

성능을 위해 열·유동 계산은 2픽셀 간격의 격자에서 활성 타일만 처리하고, 화면에는 1픽셀 간격으로 표본화합니다. 이는 연소 시각 효과용 2D 근사 유체 계산입니다. 금속의 용융이나 게임 내 모든 재질로 번지는 연소는 포함하지 않습니다.

검증: 전투·장갑 파괴 검증을 유지하면서 연료 소모, 연기 생성, 이웃 화원 사이의 열 혼합, 이동한 화원의 이전 위치에 남는 열, 장갑 셀 내부의 기체 배제, 재출격 시 전체 상태 초기화를 확인했습니다. 브라우저 시험장에서도 포격과 기체 확산을 확인했고 콘솔 오류는 없었습니다.

## 0.4 — 전장 전체 화면과 측면 홀로그램

게임 캔버스가 창 전체를 채우며, 남는 바깥 여백과 하단 계기판을 제거했습니다. 창의 비율에 맞춰 전장을 더 넓게 또는 높게 보여 주므로 함선의 픽셀 비율이 찌그러지지 않습니다. 화면 크기를 바꾸어도 진행 중인 전투와 월드의 열·연료·속도 상태는 유지합니다.

선체 보존율·기관·고도·속도는 왼쪽, 포신 온도·고폭탄 재장전·격침 정보는 오른쪽의 녹색 홀로그램으로 옮겼습니다. 계기판에는 얇은 투영 괄호, 잔광과 간헐적인 미세 떨림을 적용했습니다. 계기판은 마우스 입력을 막지 않으며, 화면 흔들림을 끄면 계기판의 투영 움직임도 멈춥니다. 화면 밖 적의 표식은 계기판을 가리지 않도록 안쪽에 배치합니다.

조작키 안내는 우측 상단 설정창에서 확인할 수 있습니다. 전투 화면 하단에는 조작키 설명을 표시하지 않습니다. 좁거나 낮은 창에서는 설정창 안에서 스크롤할 수 있습니다.

검증: 1914×819, 700×668, 1280×720 비율에서 내부 해상도·영상 버퍼·기존 월드 상태 유지를 검사했습니다. 브라우저에서는 와이드 및 기본 창의 배치, 설정 내 조작키, 계기판 위 클릭의 사격 입력 통과를 확인했습니다. 전투·파괴와 공유 기류 검증도 통과했습니다.

## 0.5 — 중앙 투영 타이틀

상단 중앙의 IRONWAKE 로고, 리본형 부제, 큰 CAMPAIGN 버튼, 2×2 보조 메뉴, 하단 작전 표 순서로 타이틀을 재배치했습니다. 로고는 길고 가는 세리프를 직접 그린 인라인 SVG로 구성하며, 외부 폰트 없이 표시됩니다. 황록색 잔광, 얇은 가로 스캔, 투영 잔상과 미세한 흔들림을 적용했습니다. 청록색 유리 배경에는 작은 물방울과 표면 흠집을 더했습니다.

메뉴의 OPTIONS는 설정, FLIGHT RANGE는 사격 시험장, CONTROLS는 조작키 안내, AUDIO는 음향 켜기·끄기로 연결됩니다. CAMPAIGN은 기존 교전을 시작합니다. 화면 흔들림을 끄거나 OS에서 움직임 줄이기를 켜면 타이틀 움직임도 멈춥니다.

검증: 기본 화면 및 참고 이미지와 같은 556×359 비율의 표시를 확인했습니다. 타이틀 메뉴의 각 기능, 설정의 흔들림 제어, 시험장과 실제 작전 진입을 브라우저에서 확인했고 콘솔 오류는 없었습니다. 기존 화면 비율·영상 버퍼·월드 상태 유지 검사도 통과했습니다.

## 0.6 — 전투 화면 상단 정리

전투 중 상단에 표시하던 작은 IRONWAKE 로고·부제, 전술 통신망 문구, 소리·설정·일시정지 버튼 줄을 제거했습니다. Esc로 일시정지하면 계속하기와 설정 버튼이 나타납니다. 음향 켜기·끄기는 설정창 또는 M 키로 조절합니다. 타이틀 화면의 로고와 메뉴는 유지합니다. 브라우저에서 상단 요소 제거, Esc 일시정지, 설정 접근 및 전투 복귀를 확인했습니다.

### 접지 후 재이륙 수정

접지 처리에서 상승 속도의 부호까지 뒤집어 지면에 고착되는 문제를 수정했습니다. 이동 적분 후 충돌을 해소하며, 하강 속도만 0으로 제한합니다. 정상 기관의 W/위쪽 방향키 재이륙, 부드러운 착륙과 정지 유지, 강착륙 손상, 기관 소실 시 양력 상실, 기관 절반 상태의 긴급 추력 이륙, 상단 경계 제한을 회귀 검사했습니다. 실제 브라우저에서도 S로 바닥 고도 25m까지 하강한 다음 W로 고도 127m까지 재이륙을 확인했습니다.

## 0.9 — 선체 디테일, 분사 화염, 검은 연기, 착륙장치

참고 이미지의 질감과 기계적 분위기를 반영해 독자적인 낮은 갑판과 비대칭 함교 실루엣을 제작했습니다. 장갑 카세트, 금속 모서리의 명암, 볼트, 배관, 압축기 핀, 노즐 립을 실제 파괴 가능한 픽셀에 배치했습니다. 기존 재질 셀과 장갑 파괴·엔진 손실·연료 유폭을 유지합니다. 제한된 기본색에 12개의 공학 재질 명암 색을 추가했습니다.

추진기는 애니메이션 이미지가 아닌 월드 좌표의 고속 가스 입자를 방출합니다. 입자는 선체 속도와 노즐 방향, 추력, 난류에 따라 이동하고 식으며, 지면에서 옆으로 퍼집니다. 엔진이 파괴되면 해당 노즐의 분출이 멈춥니다. 최대 1,400개입니다.

## 0.10 — 파괴되는 착륙장치와 지면 접촉 물리

고정된 바닥 충돌 높이를 없앴습니다. 현재 남아 있는 선체 재질 셀과 착륙장치의 렌더링 셀에서 지면 접촉 형상을 계산합니다. 선체의 남은 재질로 무게중심과 회전 관성을 갱신하고, 접촉점에서 수직 반력과 마찰 충격량을 계산합니다. 공중 자세 제어는 회전 토크를 사용하며, 착지 후에는 자동 호버를 줄여 실제 하중이 지지점에 걸립니다. W/위쪽 방향키로 재이륙할 수 있습니다.

착륙장치는 장착부·상부 링크·유압 램·발판에 독립된 내구도를 가집니다. 외부 다리도 실제 포탄 충돌과 폭발 피해를 받습니다. 상위 부품이 끊어지면 연결된 하위 부품이 함께 분리되어 함선 속도와 회전을 이어받아 떨어집니다. 선체 쪽 장착부가 파괴되어도 다리가 분리됩니다. G 전개/회수는 파괴된 부품을 복구하지 않습니다.

한쪽 다리를 완전히 잃으면 남은 다리의 반력 때문에 파손된 방향으로 기울어지고, 그쪽 선체가 지면에 닿으면 새로운 지지점이 생깁니다. 양쪽 다리를 잃으면 잔여 선체 셀이 직접 바닥에 닿습니다. 파괴된 다리의 이전 충돌 높이는 남지 않습니다. 파편의 바닥 처리는 회전된 크기를 반영하도록 보완했습니다. 타이틀과 함선 이름의 복구된 표시 스타일은 유지했습니다.

검증: 양쪽 정상 지지, 좌/우 다리 파괴 시 각각 약 -14.3/+13.6도 방향으로 기울어 안정화, 양쪽 파괴 후 선체 직접 접촉, 다리 외부 피격과 장착부 손실, 파괴 상태의 전개/회수 유지, 접지 후 재이륙을 검사했습니다. 전체 전투·유폭·가스 연소 검사, 화면 크기 변경 검사, 기존 착륙장치 전개·회수 검사 통과. 브라우저에서 세 상태를 실제 접촉 솔버로 시각 확인했고 게임에서도 착륙 후 169m까지 재이륙을 확인했습니다. 콘솔 오류 없음.

IRONWAKE-v010-contact-physics.png는 실제 게임 코드의 지면 접촉 솔버를 사용하는 검증 장면입니다. 왼쪽부터 정상, 우현 다리 완전 파괴, 양쪽 다리 완전 파괴이며, 녹색 표시는 계산된 지면 접촉점입니다.


## 0.11 — 영문·숫자 Departure Mono, 실제 재질 충돌과 조건부 폭발

영문 A–Z/a–z와 숫자 0–9에만 Departure Mono 원본 WOFF2를 적용했습니다. CSS unicode-range로 범위를 제한해 한글은 모나를 유지합니다. 캔버스 표기에도 같은 글꼴 선택 규칙을 적용했습니다. 타이틀의 큰 IRONWAKE SVG는 변경 전과 바이트 단위로 동일함을 검사했습니다. 공식 배포: https://departuremono.com/ , 글꼴 저작권 Helena Zhang, SIL OFL 1.1. 라이선스는 HTML 주석과 dist/FONT-LICENSE.txt에 포함합니다.

함선 충돌은 실제 재질 픽셀과 착륙장치 셀의 교차를 검사하는 2D 복셀 방식입니다. 큰 경계 상자는 후보 제외에만 사용합니다. 구멍과 틈에는 상대 선체가 들어갈 수 있으며, 남아 있는 재질이 실제로 닿아야 접촉이 생깁니다. 좁은 접촉면의 장갑이 버틸 수 있는 힘을 제한해 작은 돌출부 하나가 큰 함선을 즉시 정지시키지 않게 했습니다. 속도에 따라 이동을 여러 단계로 나누고, 실제 질량·접촉점·회전 관성에 따라 수직·마찰 충격량을 교환합니다.

충격량과 접촉 면적에 따라 접촉 셀의 피로와 내구도가 감소합니다. 장갑 가장자리가 어두워지고, 일부 금속 셀은 연결된 빈 공간으로 밀려 접힌 가장자리를 만들며, 나머지는 파편으로 떨어집니다. 새로 생긴 불규칙한 틈과 돌출부가 후속 충돌에 그대로 반영됩니다. 일반 장갑 충돌은 금속 파편·스파크·마찰 연무만 만들며 전체 폭발을 호출하지 않습니다.

연료통과 엔진은 직접 받은 재질 손상과 순간 충격의 기록을 별도로 가집니다. 실제 파손 또는 충격 임계치를 넘은 해당 부품만 짧은 지연 후 국소 폭발하고, 그 피해가 다른 위험 부품에 도달하면 연쇄 폭발합니다. 연료 누출은 폭발 전에 작은 화염으로 표시됩니다. 멀쩡한 연료통이 연결 단절로 떨어졌다는 이유만으로 폭발하지 않습니다. 함교/선체 무력화의 강제 폭발·무작위 연쇄 폭발도 제거했습니다. 폭발성 포탄의 탄두 폭발은 별도입니다.

추진 입자는 동일한 시뮬레이션을 유지하면서 픽셀 출력을 하나의 래스터 그리기로 묶어 렌더링 호출을 줄였습니다.

검증: 빠른 장갑 충돌의 국소 파괴와 무폭발, 저속 접촉의 무파괴, 경계 상자만 겹치는 경우의 무충돌, 포크 모양 틈에 상대 재질이 들어가는 경우, 비폭발성 기함 손실, 온전한 연료통의 분리, 노출 연료통 직접 압괴 후 지연 폭발, 엔진 직접 손상 폭발을 검사했습니다. 기존 전체 전투·유폭·연소 격자 검사 및 착륙·다리 파괴·재이륙·전개/회수 검사를 통과했습니다. 실제 브라우저에서 영문/숫자 교체와 한글·큰 타이틀 유지, 장갑 충돌 검증 장면과 콘솔 오류 없음을 확인했습니다.

IRONWAKE-v011-collision.png는 실제 게임 충돌·재질 파괴 코드를 사용하는 근접 검증 장면이며 하단에 파괴 셀 수와 위험 부품 폭발 횟수를 표시합니다.


### 무력화 시 연쇄 폭발 복구

사용자 요청으로 함선 무력화 시 최초 폭발, 4회의 시차를 둔 선체 유폭 및 잔류 화염을 복구했습니다. 일반 장갑 충돌의 국소 압괴와 위험 부품 조건부 폭발은 유지합니다. 무력화 처리 중복 호출로 연쇄 폭발이 중복 예약되지 않는 것과 일반 충돌의 무폭발을 회귀 검사했습니다.
